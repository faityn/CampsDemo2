# Mongolia Stays — 3 Camp Intro Page

A premium English-language landing page for three independent Mongolian tourism camps:

- Hoyor Zagal — Bulgan Province, Mongolia
- Alungoo Ger Hotel — Terelj National Park, Ulaanbaatar, Mongolia
- Guru Eco Complex — Terelj National Park, Ulaanbaatar, Mongolia

## Stack
- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- Lenis smooth scroll
- Swiper dependency retained for future gallery/section use

## Main concept
All three destinations are visible immediately on the landing page as three large cinematic cards. Hovering a card reveals the description and the card links directly to the camp's website.

## Run
```bash
npm install
npm run dev
```
